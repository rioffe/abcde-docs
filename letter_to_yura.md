Там описано, как три репозитория работают вместе: какие таблицы общие у скраперов и сайта, как идёт ночное обновление, какие внешние сервисы используются. Есть и список замечаний по коду (`THINGS_TO_LOOK_AT.md`).

Главное там два документа. Их лучше читать в PDF, там схемы уже нарисованы:

1. **Предложение по архитектуре:**
   https://github.com/rioffe/abcde-docs/blob/main/PROPOSAL_architecture_consolidation.pdf

   Скрапер для Barbora когда-то сделан копией скрапера для Rimi, и с тех пор копии разошлись. Из 70 общих Python-файлов отличаются 27. Сама формула Nutri-Score одинаковая. Разное другое: как продукт относится к категории Nutri-Score, правила NOVA и очередь заданий. Например, воркер Barbora не забирает задание, если упавший воркер его бросил.

   Я предлагаю менять всё по шагам, начиная с самого дешёвого:
   - проверка общей схемы базы;
   - постоянный хостинг для воркеров;
   - общий пакет для расчёта оценок;
   - позже — одна кодовая база скраперов;
   - дерево категорий, которое не зависит от Rimi.

   В конце шесть решений (D-01…D-06), по каждому моя рекомендация.

2. **План переезда с Replit на AWS:**
   https://github.com/rioffe/abcde-docs/blob/main/AWS_MIGRATION_PLAN.pdf

   Два сервера EC2: `t4g.small` для сайта и `t4g.medium` для обоих скраперов. Базы пока остаются в Neon. Цены я брал из прайс-листов AWS. Во Франкфурте это примерно $661 в год без резервирования и около $453 с резервированием на год. Если перенести базы в RDS, около $1067 в год. Там же расписаны шаги переезда с откатом и пять решений (M-01…M-05).

   **Есть вопрос, который нужно выяснить в первую очередь:** кому принадлежат базы. По коду похоже, что часть баз создана через Replit. Тогда аккаунт Neon принадлежит Replit, и при закрытии проектов на Replit эти базы пропадут. Их нужно заранее перенести в свой проект Neon. Как проверить, написано в разделе 3a.

**Вопросы про MCP-сервер**

Сайт пересылает запросы с `https://abcde.lv/mcp` и страницы `/lv/mcp`, `/en/mcp`, `/mcp-site/*` на `https://abcde-mcp.replit.app` (`mcpMachineProxy.ts`, `mcpPageProxy.ts`). Код самого сервера я не нашёл: среди твоих публичных репозиториев на GitHub его нет. В `ABCDE-Web-EU/docs/abcde-mcp/` есть только описание и `START-PROMPT.txt`, из которого 24 октября предлагалось создать отдельный проект на Replit. Поэтому вопросы:

1. Где лежит код MCP-сервера? Это только проект на Replit, или есть git-репозиторий (на GitHub, может быть приватный)? Можешь дать мне доступ?
2. Чей это проект на Replit — твой личный или командный? Кому принадлежит адрес `abcde-mcp.replit.app`?
3. Сервер читает только публичное API сайта (`/api/products`, `/api/categories`, как в `docs/abcde-mcp/API-REFERENCE.md`), или у него есть другие источники и секреты? В `START-PROMPT.txt` (строка 201) сказано хранить счётчики для `/mcp-site/stats` в собственной управляемой базе проекта. Если так и сделано, это, скорее всего, ещё одна база, созданная через Replit, и её тоже придётся переносить. Где она и кому принадлежит?
4. Какой адрес подключён в Claude как connector — `https://abcde.lv/mcp` или напрямую `https://abcde-mcp.replit.app/mcp`? Если напрямую, то при переезде этот адрес поменяется у всех пользователей.
